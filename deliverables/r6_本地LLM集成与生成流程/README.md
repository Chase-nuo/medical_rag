## 核心结果

### 环境探测：`format='json'` 在这个模型上无效

| 实验 | 耗时 | tokens | 正文 |
|---|---|---|---|
| `format='json'` | 23.3 s | 141 | 仍带 ` ```json ` 围栏 |
| 仅靠 prompt 要求 | 20.5 s | 199 | 同样带围栏 |

两种直接 `json.loads` **都失败** → 所以本阶段的核心是**容忍真实输出的提取修复器**，而不是调 JSON 模式。

### JSON 提取修复器

9 条离线自检用例：标准 / 围栏 / 解释文字 / 尾逗号 / 中文引号 / 未闭合截断 / thinking 混入 / 单引号 / 非 JSON，**全部正确处理**（非 JSON 如实返回 `None`，不编造）。两段真实模型输出也提取成功。

自检抓到并修掉一个 bug：括号补全第一版分别统计 `{}` 与 `[]`，嵌套截断时两种都补才合法，已改为**栈式扫描、后开先闭**。

### fast 完整流程实测

| 阶段 | 耗时 | tokens |
|---|---|---|
| 检索 + 上下文组装 | 177.8 s | 0 |
| 答案草稿 | 103.1 s | 572 |
| **合计** | **280.9 s** | |

答案 1121 字符，引用来源 12 条；模型原文没有来源清单与免责声明，**由后处理代码自动补齐**。

### 完整四阶段流程实测

| 阶段 | 耗时 | tokens |
|---|---|---|
| 检索 + 组装 | 63.3 s | 0 |
| 证据评估 | 187.7 s | 665 |
| 答案草稿 | 130.2 s | 818 |
| 批判性审查 | 126.9 s | 832 |
| 最终组装 | 156.5 s | 1000 |
| **合计** | **664.6 s（11.1 分钟）** | 3315 |

**评估筛选生效**：12 块 → **8 块**（可用编号 `[3,4,5,6,8,9,10,12]`），上下文 token 由 1406 降至 **936**。

**fast vs 完整（同一查询）**：完整模式未出现 fast 里的"坏血病""提高 LDL""MG3-"等可疑表述，血脂表述方向也正确。多花 2.4 倍时间换来错误消失——但只有 1 条查询，**不能推广为普遍结论**。

### 测试 query 集（3 条 fast）

| 查询 | 总耗时 | 答案长度 | 来源数 | tokens |
|---|---|---|---|---|
| 二甲双胍对心血管疾病有何影响？ | 243.7 s | 1174 | 12 | 1151 |
| SGLT2 inhibitor heart failure hospitalization | 141.3 s | 1192 | 9 | 897 |
| MI 患者的死亡率 2020年以后的研究 | 130.1 s | 1108 | 12 | 738 |

平均 **171.7 s/条**，草稿失败 0、降级警告 0。首条慢（检索 69.8 s，含重排模型冷启动），后两条检索仅 ~10 s——**流水线对象复用生效**。第 3 条"2020 年以后"的时间过滤生效（引用均为 2020 后文献）。fast 模式仍有中英混杂与术语错误（如把 LVEF"射血分数"写成"射影面积"）——引用是真的，措辞是错的。

### 测试中抓到的 bug：筛选后引用悬空

答案里出现 `[12]`，而筛选后来源列表只有 8 条。原因是筛选重建上下文时按 `1..k` 重新编号，模型却沿用评估文本里的旧编号。已改为**保留原编号**（允许 `[3][4][8]` 这样不连续），离线验证标题行 / 评估文本 / 答案引用 / 来源列表四者一致。

### 降级策略（实测驱动的设计）

1. 评估解析不出可用编号 → **保留全部上下文**（评估器有"无可用证据"误报，照筛会清空上下文）
2. 编号与块对不上 → 保留全部
3. 审查失败 → 用草稿；终稿失败 → 退回草稿 + 后处理

## 必须坦白的问题

**fast 模式答案出现多处可疑表述**：如"降低**坏血病**风险"（坏血病与心血管无关）、"**提高**低密度脂蛋白胆固醇"、含义不明的"MG3-"。后处理只能补格式，**补不了事实**——这是跳过评估与审查的代价。

## 已知局限

1. **延迟高**：fast 单条 ~280 s，完整四阶段约 9~15 分钟
2. **答案事实正确性无自动评判**：引用正确 ≠ 陈述正确，需医学背景人工评审
3. **证据筛选不可复现**：上一阶段已发现 `temperature=0.0` 下评估结果会变，本阶段的筛选因此也不稳定，故默认"解析失败保留全部"
4. **无标注集**：无法计算答案层面的准确率指标
